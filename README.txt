# Monik Wadhwani — Personal Website

Hi! I'm Monik, currently pursuing BBA in Digital Business and Entrepreneurship at IIM Bangalore.

This website is a small space where I share my background, interests, learning journey and things I'm exploring.

### What's inside?
- **About:** A little introduction about me.
- **Interests:** Business, creativity, technology and sports.
- **Field Notes:** Thoughts, observations and things I learn along the way.
- **Journey:** My education and current learning experiences.

### Built With
- HTML
- CSS

The website uses responsive layouts and a simple editorial-style design. The Work in Progress theme reflects my belief that learning and building are ongoing processes.

### Files
- `index.html` — Website structure and content.
- `style.css` — Styling, layout and responsive design.
